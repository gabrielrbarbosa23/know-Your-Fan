# Know Your Fan

Projeto desenvolvido para coletar informações sobre fã de esports com formulário e painel administrativo.


## 💡 Funcionalidades

- Formulário com coleta de dados (nome, e-mail, endereço, CPF, interesses e eventos).
- Dashboard com tabela dos fãs cadastrados no Firebase.
- Integração com Firebase (Firestore).
- Estilização simples e clara.
- Código organizado por componentes React.


## 🚀 Tecnologias

- React + Vite
- Firebase (Firestore)
- JavaScript (ES6+)
- CSS
- Git
- Github


## 🛠️ Como rodar o projeto localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/know-your-fan.git


2. Instale as dependências:

npm install

3. Inicie o servidor React:

npm run dev

4. Em outro terminal, vá até a pasta backend e inicie o servidor Node:

cd backend
node index.js
```
